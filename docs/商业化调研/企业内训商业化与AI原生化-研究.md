## 0. 核心结论（TL;DR）

1. **赛道格局**：国内企业培训（eLearning / 数字化学习）已从"课程+平台"切换到"AI Learning"叙事。2025 年是拐点年——北森 1.8 亿元收购酷学院（2025-01，"2025 年 SaaS 首单并购"）、云学堂更名"绚星智慧科技"并押注 AI（2025-03）、各家统一话术变成"N 大 AI Agent 覆盖萃-学-练-考-评"。
2. **AI 原生化的真实落地形态**已相当收敛：**AI 做课（文档/PPT→课程/题库）**、**AI 陪练（roleplay 对话）**、**AI 学习助手（RAG 答疑+推荐）**、**AI 考试（出题+阅卷）**、**AI 能力差距诊断**五件套。**自适应路径/知识追踪**在国内厂商官网上多为概念描述，公开可验证的实现（BKT/DKT/遗忘曲线建模）主要集中在**学术论文与教育科技（松鼠Ai）**，企业培训 SaaS 里缺乏公开算法细节与效果 A/B 数据。
3. **本体+大模型这条路径，在国内企业培训产品里几乎无公开对标物**——各家能力模型（胜任力模型）多为人工配置的静态词表/标签体系，**没有一家公开宣称用 OWL/RDF 本体 + 规则推理做能力点图谱**。这既是我们的差异化机会，也是"客户听不懂"的教育成本。
4. **定价**：国内 SaaS 主流 **¥2,680–¥69,800/年**（按版本/功能，含存储、人数档），UMU 单教师 ¥4,800/年；海外 LMS 走 **按活跃用户（MAU/RAU）报价**，Docebo 成交中位数 **$41,651/年**（区间 $21k–$102k）。**国内按人年报价基本不公开**，均为"按企业规模/模块灵活定价"。
5. **合规是硬门槛且被低估**：只要"面向公众提供"生成式 AI 服务，就要**算法备案 + 大模型备案或登记**；考场**人脸识别**受 2025-06-01 施行的《人脸识别技术应用安全管理办法》严格约束（不得为唯一验证方式、人脸信息原则上不得联网传输、≥10 万人须备案）；员工能力画像触发**个保法敏感个人信息 + 自动化决策**条款。
6. **政企采购**：软著 + 第三方检测报告 + 等保（通常二级，涉密/重要系统三级）+ 信创适配（统信/麒麟/达梦/鲲鹏/飞腾）已成标配，且国资央企有 2027 全替代时间表。

### 1.3 对标小结（对我们最重要的判断）

- **国内头部已全部转向"AI Agent 矩阵"叙事**，和我们的"文档→能力点→出题→自适应→考评"链条高度重叠，但**它们的能力点体系是"人工胜任力模型+标签"，不是本体**。
- **一体化是核心护城河**：北森、Cornerstone、SAP 的卖点都是"培-测-盘-绩数据贯通"。我们若只做培训孤岛，会被一体化平台挤压；**我们的本体恰好是"打通"的天然载体**（能力点本体可挂招聘/绩效/盘点）。
- **"练"取代"学"成为价值主张**：北森"三分学七分练"、UMU 全是对练工具。**我们的自适应+考评若不能产出"练"的场景（对话对练/实操演练），会被认为落后**。

### 2.2 关键判断

- **"AI 出题"已红海化且门槛低**（金数据、优考试、弘成、JD 云都在做），**单点"文档→题目"不构成壁垒**。我们的结构性差距在于**"能力点本体"这一中间层**：它让出题可溯源到能力点、让考评可回填能力画像、让路径可基于能力差距生成——这是"题库工具"做不到的。
- **自适应/知识追踪是"纸面强、落地虚"的地带**。如果我们能用 BKT/DKT/遗忘曲线做出**可验证的自适应**（哪怕小范围 A/B 数据），就能形成国内厂商普遍缺的硬证据。参考 `adaptive-learning-algos` / `learning-recall-mastery-design` 技能。
- **效果数据的行业现状**：全网公开的"提升 X%"几乎全是厂商自述，**没有任何一家提供第三方审计的效果报告**。这既意味着我们不必因缺数据自卑，也意味着**谁先拿出可复现的对照实验，谁就拿到话语权**。

**国内模式特征**：
- **SaaS 按版本+年费**（¥2.7k–¥70k/年）为公开主流，**按人年报价基本不公开**，实际大客户走"定制报价"。
- **私有化买断/源码买断**是政企/金融/央国企的常见形态（一次性授权+年维护），公开报价缺失。
- 国内 SaaS 普遍**捆绑课程内容**（酷学院 1.5 万门、知学网 2000+ 门、平安知鸟 20 万门）——**内容即毛利来源之一**。
- **按调用量计费**（token/次）在国内企业培训 SaaS 公开报价中【未找到公开资料】。

### 3.3 商业模式对标的启示

1. **"平台 + 内容 + 运营"三位一体**是头部通用话术（平安知鸟、酷学院、企学宝均如此），我们若只有平台，客单价上不去。
2. **国内按人年难落地**——客户习惯"买版本/买模块/买断"，我们定价应**版本档 + 模块加购 + 私有化买断**三轨并行，而非照抄海外 MAU 模型。

## 4. 合规红线（生成式 AI / 算法备案 / 等保 / 个保法）

### 4.1 生成式人工智能服务管理暂行办法（2023-08-15 施行）🟢

**原文已抓取并核对**：https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm

对我们直接相关的条款：

- **第二条（适用范围）**：利用生成式 AI 技术**向境内公众**提供生成文本/图片/音频/视频服务的，适用本办法。**"未向境内公众提供生成式人工智能服务的，不适用"**——即**纯企业内部自用、不对外开放**，不触发。
- **第四条**：不得生成违法内容；防止**民族/信仰/性别/年龄/职业/健康等歧视**；尊重知识产权；不得侵害肖像权/名誉权/隐私权/个人信息权益；提升生成内容透明度与准确性。
- **第七条（训练数据）**：使用**具有合法来源**的数据和基础模型；涉及个人信息的**应当取得个人同意或符合法定其他情形**。
- **第九条**：提供者承担**网络信息内容生产者责任**与**个人信息处理者责任**；须与使用者签服务协议。
- **第十二条**：AI 生成的图片、视频等须按《互联网信息服务深度合成管理规定》**标识**。
- **第十七条（关键）**：提供**具有舆论属性或者社会动员能力**的生成式 AI 服务的，应按国家规定**开展安全评估**，并按《互联网信息服务算法推荐管理规定》**履行算法备案**。

### 4.2 算法备案 / 大模型备案 / 大模型登记（三件套辨析）🟡

**律所解读来源**：https://www.guantao.com/page4747 （观韬）｜https://www.allbrightlaw.com/CN/10475/9d795e4543aa51ea.aspx （锦天城）｜火山方舟文档 https://docs.volcengine.com/docs/82379/1471389

| 业务模式 | 合规义务 |
|---|---|
| 自研大模型，直达 C 端 | **大模型备案 + 算法备案** |
| 自研大模型，经 B 端间接触达 C 端 | **大模型备案 + 算法备案** |
| 基于开源模型做了**实质性微调/二次开发** | **大模型备案 + 算法备案** |
| 仅调用已备案大模型 API，**未做任何修改** | **大模型登记 + 算法备案** |
| 仅调用 API，但**对模型输出做了二次处理（过滤/重组）** | 网信办**可能认定"实质性修改"，要求走大模型备案** |
| 算法/模型**仅企业内部使用、不对外开放** | **无强制备案/登记义务** |

- **算法备案入口**：国家网信办"互联网信息服务算法备案系统" https://beian.cac.gov.cn/ ，分主体备案+算法备案；通过后**须在产品显著位置公示备案编号**。（🟡 律所解读）
- **大模型备案**：向属地省级网信办初审→国家网信办终审，材料含《安全评估报告》《拦截关键词列表》《评估测试题集》等。（🟡）
- **大模型登记**：省级网信办审核，无需《安全评估报告》，审查调用模型是否已备案、调用协议合法性、企业内容审核能力。（🟡）
- 已备案信息公告（网信办定期发布）：https://www.cac.gov.cn/2026-05/13/c_1780413225190669.htm 🟢（公告页）

> **对我们的判断（关键）**：若我们的系统**只卖给企业内部、部署在客户内网、不面向公众**，按第二条与上表，**大概率无需大模型备案/登记**；但一旦做成**多租户公有云 SaaS 对外提供服务**，则触发**算法备案（生成合成类）+ 大模型登记或备案**。这条边界必须在产品形态决策时就钉死。

### 4.3 人脸识别技术应用安全管理办法（2025-06-01 施行）🟢

**原文已抓取并核对条款号**：https://www.cac.gov.cn/2025-03/21/c_1744174262156096.htm
（网信办+公安部令第19号，2025-03-13 公布）

**对我们的考试防作弊模块，这是最直接的红线**：

- **第五条**：应用前须以显著方式告知（处理目的/方式/保存期限/必要性及影响/个人权利）。
- **第六条**：基于同意处理人脸信息，须取得**单独同意**；须提供便捷的撤回同意方式。
- **第七条**：处理**不满 14 周岁**未成年人人脸信息的，须取得监护人同意并制定专门规则。
- **第八条（关键）**：除法律另有规定或取得单独同意外，**人脸信息应当存储于人脸识别设备内，不得通过互联网对外传输**；保存期限不得超过必需的最短时间。
- **第九条**：应用前须**事前进行个人信息保护影响评估**并记录，报告**至少保存 3 年**。
- **第十条（关键）**：实现相同目的存在其他非人脸方式的，**不得将人脸识别作为唯一验证方式**；个人不同意刷脸的，应提供其他合理便捷方式。
- **第十一条**：鼓励优先使用国家人口基础信息库、国家网络身份认证公共服务，减少人脸信息收集存储。
- **第十二条**：不得以办理业务、提升服务质量为由**误导/欺诈/胁迫**个人接受人脸验证。
- **第十三条**：公共场所安装须为维护公共安全所必需、设显著提示；**禁止在客房/浴室/更衣室/卫生间等私密空间安装**。
- **第十四条**：须采取数据加密、安全审计、访问控制、入侵检测等措施；涉及等保/关基的，履行相应义务。
- **第十五条（关键）**：**人脸信息存储数量达到 10 万人之日起 30 个工作日内**，向所在地省级以上网信部门**履行备案手续**（提交处理目的/方式/存储量/安全措施/处理规则/影响评估报告）。

> **对我们的直接动作**：考试防作弊若做人脸核验，**必须**：(1) 提供非人脸替代验证（如随机抓拍+人工复核、密码+监考）；(2) 人脸模板本地化存储、不上云；(3) 做影响评估并留档 3 年；(4) 规模上 10 万人即触发备案。**建议架构上默认"本地比对 + 不上传"，把合规成本前置消化**。

### 4.4 个人信息保护法（员工画像相关）🟡

法定条文（二手转载/律所摘录，原文见 http://society.people.com.cn/n1/2021/0823/c1008-32202785.html ；港 PCPD 摘要 https://www.pcpd.org.hk/tc_chi/data_privacy_law/mainland_law/mainland_law.html ）：

- **第十三条（核心豁免）**：符合下列情形之一方可处理个人信息——（二）**"按照依法制定的劳动规章制度和依法签订的集体合同实施人力资源管理所必需"**。**这是 HR/培训系统处理员工数据的合法性基础**，但**须有合法劳动规章制度+集体合同支撑**，不能默认豁免。
- **第六条/最小必要**：处理须目的明确合理、与目的直接相关、影响最小、限于最小范围。
- **第二十四条（自动化决策）**：利用个人信息自动化决策须保证**透明度和结果公平公正**；作出对个人权益有重大影响的决定，个人有权要求说明并**有权拒绝仅通过自动化决策作出决定**。
- **第二十六条**：公共场所图像采集/身份识别设备须为维护公共安全所必需、设显著标识，收集信息**只能用于公共安全目的**。
- **第二十八条**：**生物识别**信息属**敏感个人信息**。
- **第二十九条**：处理敏感个人信息须取得**单独同意**。
- **第五十五条**：处理敏感个人信息、**利用个人信息进行自动化决策**、向第三方提供/公开、跨境提供等情形，须**事前个人信息保护影响评估**，报告**至少保存 3 年**。
- **第五十八条**：重要互联网平台应成立外部成员为主的独立监督机构等（规模大的 SaaS 才涉及）。

> **对我们的直接卡点**：「员工能力画像」= 个人信息 → 若画像用于**自动化决策**（如自动判定晋升/淘汰/评级）→ 触发第 24 条（个人可拒绝纯自动化决策）+ 第 55 条（影响评估）。
> **建议**：能力画像定位为**"辅助诊断"而非"自动裁决"**，保留人工确认环节；培训/考试数据处理写进经民主程序制定的劳动规章制度；敏感项（人脸/行为）单列单独同意。

### 4.5 其他相关法规（补充）

- **《人工智能生成合成内容标识办法》**（2025-09-01 施行）：生成内容须加**显式标识**（文字/声音提示）和**隐式标识**（元数据）。原文：https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm 🟢；配套强制国标 **GB 45438-2025**《网络安全技术 人工智能生成合成内容标识方法》。→ **我们 AI 生成的课件/题目若对外发布，需带标识**。
- **GB/T 45654-2025**《网络安全技术 生成式人工智能服务安全基本要求》——大模型备案的安全评估依据。🟡
- **《网络数据安全管理条例》**（国务院令）：数据处理者义务、跨境等。🟡

### 4.6 等保 2.0 🟡

- 依据 **GB/T 22240-2019** 定级，流程=**定级→备案→建设整改→等级测评→监督检查**。
- **二级**：地市级以上国家机关、企业事业单位等一般系统；**三级**：重要行业/领域信息系统，需**专家评审（三级需 3 名以上专家）**、现场技术检测/渗透测试。
- 培训系统**通常定二级**；涉密、承载大量敏感个人信息或关基相关场景可能定三级。
- 出处：https://www.sangfor.com.cn/knowledge/classified-protection ；https://dengbaoceping.org/index.php/2026年等保备案全流程操作指南/ ；https://www.secrss.com/articles/506 🟡
