# 需求：规则引擎加"实体总数"模板（支持"有多少台设备"）

> 背景：多文件建模后，"有多少台设备/产品"问答答不上（返回"[图检索] 未定位"）。根因：规则引擎的"数量: 状态/类型/区域"模板只支持"类型值"（如"空压机"是 deviceType 值），不支持"实体类总数"（"设备"是实体类，非类型值）。
> 用户关注：查询问答能力完整。修复：规则引擎加"实体总数"模板。

## 目标文件
- `E:\open-source\factory-ontology-kit\codes\ontology_qa_v3.py`（规则引擎 answer）

## 现状
data 结构：`{实体URI: {属性: 值}}`，如 `{'Valve_equipment_E1': {'deviceName':'数控车床','deviceType':'机加设备','status':'运行中'}}`。实体 URI 形如 `<表名>_<id>`（Valve_equipment_E1）。

规则引擎"数量: 状态/类型/区域"模板（ontology_qa_v3.py 约 240-250 行）：
- status 类型：`_find_enum(D, q, "status")` 匹配状态枚举
- type 类型：`_find_enum(D, q, "type")` 匹配 deviceType 值（如"空压机"）
不支持"有多少台设备"（设备是实体类，非类型值）。

## 要求
加"实体总数"模板（排在类型模板之前或之后）：
1. 检测问题含"多少台/个/条 X"或"X 总数"（X 是实体类名，如 设备/产品/客户/批次/原料）
2. 从 data 的实体 URI 识别实体类：URI 前缀（Valve_equipment → 设备）。需要实体类名 → 中文名的映射
   - 方法：从词典或 data 键推断。设备类名 Valve_equipment 含 "equipment"/"设备"；产品 Valve_products 含 "product"
   - 或加个实体类中文名映射：`{"equipment":"设备","product":"产品","customer":"客户","batch":"批次","raw_material":"原料","sale":"销售","qc":"质检"}`
3. 匹配后统计该类实例数：`n = sum(1 for k in data if 实体类匹配(k))`，返回"有 N 台设备"或"设备总数 N"
4. 不破坏现有"空压机"类型计数（保留原模板）

## 极简实现
- 加实体类中文名→URI子串 映射表
- 在 answer 加一个分支：识别"多少台/个/条 + 实体类词" → 统计
- 复用现有 data 结构，不改 build_data

## 约束
- 极简，只加一个模板分支
- 不破坏现有规则模板（状态/类型/组合/极值等）
- 中文处理正确
