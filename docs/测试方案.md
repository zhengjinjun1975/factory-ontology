# factory-ontology 交付测试方案（落地工厂工程视角）

**测试主体**：factory-ontology v2.7.1（本体驱动的中小工厂知识库问答 + 溯源系统）
**测试方式**：多 Agent 并行拆解 + 全量实测（自动化 + 端到端）
**产出**：统一交付测试报告

## 一、测试范围（落地工厂工程视角分 5 层）

### L1 数据落地层（工厂数据能否进系统）
- `data_loader` 多格式读取（CSV/JSON/SQLite/Excel）
- `multi_table` 多表关联建本体（外键、join 表去重）
- `new_kb.py` 新知识库引导（落地第一入口）
- `data_quality` 数据质量校验

### L2 问答/检索层（工厂最常问的问题能否答）
- `ontology_qa_v3` 规则引擎（结构化：数量/极值/过滤/计数）
- `graph_rag` 开放式/关系问题（图遍历 + LLM）
- benchmark（规则 100%）+ benchmark_graphrag（开放式命中率）

### L3 API/业务层（系统对外能力）
- 全部端点：ask / trace.forward / trace.reverse / scan / stats / metrics / audit / kbs / sync / app-config / admin.rebuild
- 角色化鉴权（admin/read）
- 多租户（kbs.json）+ 实时同步

### L4 交付层（用户实际用的东西）
- APP/PWA（manifest/sw/icon/动态品牌）
- 语音助手（STT 本地模型 + edge-tts）
- Docker/部署（Dockerfile/docker-compose/nginx）

### L5 工程一致性（可交付的质量门槛）
- pytest 全过、版本一致、工作区干净、无死代码残留

## 二、Agent 拆解（并行 3 个）

| Agent | 负责层 | 测试内容 |
|-------|--------|----------|
| Agent-A | L1+L2 | 数据落地 + 问答/检索（数据层 + 规则引擎 + GraphRAG + benchmark） |
| Agent-B | L3 | API 业务层（全端点 + 鉴权 + 多租户 + 审计 + 同步 + app-config） |
| Agent-C | L4+L5 | 交付层 + 工程一致性（APP/PWA/语音 + Docker + pytest + 版本 + 死代码） |

## 三、落地细节（工厂用户关注点）

1. **数据进得来**：任意 CSV/Excel/DB 能建本体，new_kb 一键搭骨架
2. **问题答得上**：结构化 100%、开放式有命中率实证
3. **溯源查得到**：正/反向溯源、扫码（食品安全/召回核心）
4. **部署得起**：Docker 一键、无依赖墙
5. **APP 用得了**：手机可装（PWA）、品牌自动适配
6. **数据换得了**：换数据只换配置，不碰代码

## 四、执行

1. 派 3 个 Agent 并行跑 L1-L5
2. 各 Agent 返回测试结果（通过/失败/证据）
3. 统一合成交付测试报告
