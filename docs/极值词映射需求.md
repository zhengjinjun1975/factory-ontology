# 需求：极值词映射泛化（"最贵/最便宜/最大/最高"等 → 对应字段）

> 9 行业向量混合检索后 95%（38/40），剩 2 个漏答：精加工/波纹管"最贵的产品"。根因：极值模板识别"最X的Y"时，"贵"字未映射到价格字段。

## 诊断
- numeric_fields 有 "价格"→price，attr_cn2en 有 "价格"→price
- 但"最贵的产品"的极值模板匹配："最"字后是"贵"，需把"贵"映射到"价格"字段（价格/贵/便宜/金额/单价 都是 price 相关）
- 极值词表目前只认"最大/最小/最高/最低"等，不认"最贵/最便宜"

## 目标文件

## 要求
1. 极值模板识别"最X"时，X 的字段推断**支持通用极值词映射**：
   - 贵/便宜/价格/金额/单价 → price/金额字段
   - 大/最大/小 → 容量/尺寸/吨位 等数值字段
   - 高/低 → 温度/价格/功率 等
   - 用 numeric_fields（中文→字段）+ 通用极值词映射推断"最X"对应的字段
2. "最贵的产品" → 推断字段 price → 极值命中（价格最高的产品）
3. 不破坏现有极值（功率最大/温度最高/投资最大）
