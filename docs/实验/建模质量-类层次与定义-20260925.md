## 1. 根因（复述 + 复核）

自动建模落盘的是 `config/ontology_schema_<kb>.json`，其 `entities[*]` **没有 `parent` 字段**、也无类节点声明 → `_check_standard` 里
`subcls = sum(1 for e in ents if e.get("parent")) == 0`；实体 6 项核心描述项（IRI/Name/Label/Definition/Properties/Subclass）中
只缺 **Subclass** 一项 → `ent_core_rate = 5/6 = 83.3%`，`standard_rate` 被 `0.10*(1 if subcls else 0)` 与 `0.35*ent_core_rate` 一起拖到 84.2。
`Definition` 其实已有（结构性定义），面板把「缺 Definition/类层次」并列展示，实际缺的是**类层次**（`ent_rate 62.5% = 5/8`：还缺 HasSubclass/EquivalentClass 两个**扩展**项）。

唯一写 `ontology_schema_<kb>.json` 的地方是 `/api/ontology/confirm`（自助建模第③步）——**过去它不产出层次、也不要求人确认层次**。

## 4. 人在环（③）：不确认不许落库

`POST /api/ontology/confirm` 现在有三道**硬校验**（任一不过 → `ok:false`，**不静默通过**）：

1. `hierarchy_confirmed != true` → 拒绝：`层次与定义未确认：请在自助建模「层次与定义确认」中确认建议的类层次与实体定义后再落库(不静默通过)`；
2. 任一实体缺 `parent`（含「人把某条边删了」的情况）→ 拒绝：`以下实体缺类层次(parent)，未确认完整，不许落库: [...]`；
3. 任一实体缺 `definition` / 确认内容里一个类节点都没有 → 拒绝。

前端 `doConfirm()` 也做同样拦截（未勾选就把确认卡片展开并给出提示），后端才是**最终闸门**。
界面：确认卡片**默认收起**（一行 `类层次 N 个类 · 实体挂载 x/y · 定义 x/y` + `已确认/未确认（不落库）` chip），点「▸ 展开」才列出三张表；每行带规则与依据，父类/定义可就地改，条目可删（删类节点会把子节点上提一级）。

## 6. 没做到 / 不确定项（不粉饰）

1. **扩展描述项仍未达标**：`ent_rate` 由 62.5% 只抬到 **75.0%**，仍是 `info`。
   缺的是 **HasSubclass / EquivalentClass** 两项。HasSubclass 需要「实体以实体为父类」（真正的 is-a 细分模型），
   EquivalentClass 需要**外部词汇对齐**（如对齐国标/行业词表）——本轮没做，也没用「随便挂一个实体当父类」去把数字刷满。
2. **R2 命名词干分组的语义强度有限**：它靠**表名共同前导词干**，是「命名证据」而非严格语义证明。
   个别库里库前缀未被全表共现时（如 `food_co` 含 `supplier`，`food` 不构成全表前缀），词干会取到库前缀本身 → 子类名成 `FoodGroup`（分组仍确定、依据仍写明，但语义偏弱）。
   `R2` 只在「同业务域内 ≥2 个实体共享词干」时触发，不刻意造树。
3. **`food_co` 的注册数据目录被纠正**：`config/kbs.json` 中 `food_co.data_dir` 由 `"data"` 改为 `"data_food_co"`。
   原因：原登记指向共享大目录 `data`，若按登记目录重跑会自动把本体从 7 实体扩到 12 实体（本人**第一次迁移就踩到了，已回退重跑**）。
   现登记与「其本体实际来源目录」一致（`data_food_co` 仅 `food_co` 使用）。**这是本轮唯一的注册表改动，已在此明示。**
4. **`valve` 词典 `lexicon_valve.json` 被流程重生成**：新文件多了行业层键（`pump_cn2en/part_cn2en/fault_cn2en`、`_industry: 泵阀`），
   `synonym_map` 有增有减（少了 `乳制品/产品/功率…`，多了 `球阀/离心泵/叶轮…`）。这是 `/api/ontology/confirm` 的既有行为（重建 nt+词典），
   **不是本轮新增逻辑**；已用回归门复核：问答评测基线、信封与未命中、KB/词典分层三门全绿（§5.3）。仍请知悉这是一处**非纯增量的副作用**。
5. **`codes/export/*` 与 `web/public/*` 为生成物**，因验证被重写（`ontology.ttl/jsonld/shapes.ttl`、`web/public/index.html` + 新 hash 资源）；未提交。
