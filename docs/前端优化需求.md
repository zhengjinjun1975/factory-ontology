# 需求：factory-ontology 前端优化（功能 + 美观，基于竞品分析）

> 依据竞品分析《工厂本体竞品分析-2026.md》（11条调整建议），聚焦前端可落地优化。
> 遵循「代码极简原则」：只做必要优化，不重写整个前端，不加无谓依赖。
> 目标：专业工业风（浅色、可信、非AI玩具感），工厂工程/管理人员可用。

## 现状
3 标签页：数据建模（上传CSV+模型结构图）、查询分析（问答+智能分析路由）、数据看板。浅色工业风（#eef1f5 底、白卡片、工业蓝 #2563eb）。功能完整。

## 优化 1：问答结果溯源展示（竞品建议2，最优先）
每个查询结果下方展示"支撑答案的实体/关系/数据"（证据溯源），增强可审计性——工厂决策关键。
- 后端 /api/ask 已有 evidence 字段（ontology_qa_v3 的 evidence.extract_evidence）
- 前端：查询结果下加"证据溯源"折叠区，展示命中的实体/属性/值
- 极简：只读已有 evidence 字段渲染，不新写后端逻辑

## 优化 2：L2 迷你关键指标卡片（竞品建议8）
分析结果（AnalysisResult）用 L2 迷你卡片展示关键指标（总数/运行数/故障率），替代全屏复杂图表。
- 现状 AnalysisResult 已有 KPI 行 + donut/bar 图（svelte skill 已验证模式）
- 优化：卡片化呈现，强调"关键指标一眼可见"，色彩克制（受限语义色：绿=正常/红=异常/蓝=信息）

## 优化 3：诊断式看板（竞品建议9）
看板从"报发生了什么"升级到"突出异常/为什么"。
- 现状 DashboardPanel 已有数据
- 优化：异常项置顶高亮（红色语义色）、关键指标黄金三角（左上）、遵守 5 秒规则（一眼看懂）

## 优化 4：企业数据分析对话（竞品建议11）
问答界面走"企业数据分析对话"而非"通用聊天"——答案结构化渲染，非纯文字气泡。
- 现状：答案用 `<pre>` 纯文本
- 优化：结构化答案用表格/列表渲染（检测表格分隔符→HTML表格），答案附来源；保持简洁不炫技

## 优化 5：美观优化（符合审美，非AI感）
浅色专业工业风强化：
- 色彩克制：语义色仅用于状态（绿/红/蓝），不滥用渐变
- 层级一致：工具栏/标签/面板间距统一，圆角克制（4px），阴影轻
- 高对比：浅底深字，关键数据可读性强
- 保持现有 #eef1f5/#d5dbe3/#2563eb 体系，只微调细节，不推翻重来

## 铁律（必须遵守）
1. **极简**：只改必要处，不重写整个组件，不加第三方图表库/框架
2. **Svelte 5 语法**：用 `$props()`/`$state()`/`$effect()`，不用 `export let`
3. **不破坏现有功能**：建模/问答/分析/看板/模型切换都要保持可用
4. **美观是专业不是花哨**：克制、可信、浅色，符合工厂工业软件惯例

## 验收标准
1. 查询结果展示证据溯源（读 evidence 字段渲染）
2. 分析结果用迷你关键指标卡片（L2）
3. 看板异常项高亮置顶（诊断式）
4. 结构化答案用表格渲染
5. `npm run build` 无 error/warning
6. 现有功能不退化（问答/建模/分析/看板可用）
