# 需求：词典 LLM 语义聚类合并同义词（DSE-RE 思路，解决别名命中）

> 依据调研《工厂本体检索优化调研-2026.md》：词典构建从"枚举值收集"升级为"LLM 语义聚类合并同义词"（DSE-RE 图语义聚类 F1+6.8%）。解决"乳制品"等别名/口语化命中问题（食品验证短板）。

## 背景问题
当前 `_build_lexicon` 从 suggest_schema 枚举收集 attr_cn2en/status_cn2en/type_cn2en——只覆盖数据里出现过的取值，**无法合并同义词**。
例：食品数据产品 category 有"乳制品"，用户问"乳制品"能命中，但问"奶制品/酸奶类"不命中；设备"机加设备"vs"机加工设备"不同写法不合并。

## 目标文件
- `E:\open-source\factory-ontology-kit\codes\multi_model.py`（_build_lexicon）

## 要求
1. 在现有 `_build_lexicon` 基础上，**加"语义聚类合并同义词"**（借鉴 DSE-RE 图语义聚类思路，用 LLM）：
   - 对收集的枚举值（type_cn2en/status_cn2en/zone_cn2en 的取值 + attr 的中文名），用 LLM 生成同义词组，合并到词典
   - 例："乳制品" → 同义词 ["乳制品","奶制品","酸奶类","乳品"]；"机加设备" → ["机加设备","机加工设备","机械加工设备"]
   - 生成 `synonym_map`：{规范词: [同义词...]}，供规则引擎/检索在匹配时展开
2. **LLM 失败回落规则**：若 LLM 不可用，保持原枚举收集（不阻塞建模）
3. 复用 model_llm.llm_generate（key 可用时）；本地优先
4. 极简：只加语义聚类步骤，不改其他建模逻辑

## 约束
- 极简，复用 model_llm
- LLM 失败回落（不阻塞）
- 不破坏现有 9/10 命中（阀门）+ 机械 9/9 + 食品 8/9
- 中文正确
- 泛化：适配任意行业数据（不硬编码食品/机械）

## 验收
1. 词典生成 synonym_map（含同义词组）
2. "乳制品"相关查询用别名（奶制品等）能命中
3. LLM 不可用时词典仍正常（回落枚举）
4. 现有查询不破坏（有多少台设备/客户总数等）
5. pytest 29 passed
