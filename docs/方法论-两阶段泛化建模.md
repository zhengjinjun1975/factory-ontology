# 方法论：两阶段泛化本体问答建模（复用优先·泛化优先）

> 基于 9 大行业（阀门/机械/食品/化工/地震/精加工/波纹管/环保/造船）横向验证，提炼的通用方法论。
> 目标：换任何行业数据，系统自动建本体 + 词典 + 查询映射，少量人工辅助即达高命中率，形成可复用的基础架构，而非逐行业修补。

---

## 一、核心洞察：问题的本质是"映射硬编码"，不是行业差异

9 行业漏答问题的共性根因：**查询映射（实体名/字段/类型/同义词）是硬编码的**，换行业即不命中。
- A. 实体总数映射硬编码 {设备:equipment,...} → 新行业实体（测线/炮点/项目/船坞/船）计数不命中
- B. 极值字段不全 → 精度/投资/价格/吨位 极值不命中
- C. 类型计数不全 → 大气治理/油轮 类型不命中
- D. 材质/属性值同义词覆盖不全

**结论**：泛化性的核心 = 让"建库时自动生成映射"替代"硬编码映射"，而非为每个行业手工补丁。

---

## 二、方法论：两阶段泛化建模

### 阶段一：规则 + 大模型 自动建模（覆盖 90%+）
**建库时自动生成全部查询映射**（data profiling + LLM）：
1. **实体识别映射**：从 suggest_schema 表名 + 中文 label 自动生成 {中文实体名: 表名}
2. **极值字段识别**：data profiling 识别数值列（精度/价格/吨位/金额/容量），自动纳入极值
3. **类型枚举收集**：枚举列 distinct 值自动进 type_cn2en
4. **属性值同义词**：枚举值 + LLM 生成同义词（synonym_map）
5. **本体构建**：suggest_schema 自动推断 schema + 多表关系

### 阶段二：精细化人工辅助（解决剩余长尾，覆盖到 98%+）
提供人工辅助界面，微调/补充自动生成的映射：
1. 映射审查界面（实体/字段/类型/同义词可增删改）
2. 词典编辑器（补未识别同义词/字段别名）
3. 失败反馈回路（"未定位"问题 → 提示补映射 → 入该行业词典）

### 兜底：运行时 schema linking
规则未命中的查询，用 schema linking（问题 + schema 元素给 LLM）动态产出映射。

---

## 三、架构重构：映射分层解耦

把"查询结构模板"与"实体/字段词汇表"解耦（结构跨域通用，词汇随行业注入）：

```
┌─────────────────────────────────────────────┐
│ 查询结构层（跨域通用，不硬编码）              │
│  - 实体总数模板: "多少[个/台/条/艘] X"        │
│  - 极值模板: "最[大/小/贵] Y"                 │
│  - 类型计数: "[类型值]的[实体]数量"           │
│  - 属性筛选: "[属性词]的[实体]"               │
├─────────────────────────────────────────────┤
│ 行业映射层（建库时自动生成 + 人工可改）        │
│  - entity_cn2en: {测线:lines, 船:vessels,...} │
│  - numeric_fields: [精度,价格,吨位,金额,...]   │
│  - type_cn2en: {大气治理, 油轮,...}           │
│  - synonym_map: {不锈钢:[CF8,304,316]}        │
│  - attr_cn2en: {精度:accuracy_mm,...}         │
├─────────────────────────────────────────────┤
│ 本体构建层（自动）                            │
│  - suggest_schema → 多表实体/关系/约束        │
│  - _build_lexicon → 行业词典                  │
└─────────────────────────────────────────────┘
```

**关键**：查询结构模板是通用的；行业映射层随建库自动生成（data profiling + LLM），且可人工精细调整。换行业 = 重建映射层，不改结构层。

---

## 四、为什么这是"为未来解决形成基础"

1. **一次性泛化**：9 行业验证的 A/B/C/D 四类根因，通过"建库自动生成映射"一次解决，而非逐行业打补丁
2. **可复用**：方法论 + 架构提炼成基础，未来任何新行业（能源/医疗/物流...）只需：数据 → 自动建库（本体+词典+映射）→ 人工微调 → 高命中
3. **分层清晰**：结构/映射/本体三层解耦，改一层不影响其他
4. **有兜底**：schema linking 兜底规则未命中；人工辅助兜底自动生成遗漏

---

## 五、落地步骤（方法论 → 实现）

1. **提炼基础架构**：multi_model 增加"自动生成 entity_cn2en/numeric_fields"；ontology_qa_v3 读行业映射替代硬编码
2. **9 行业回归**：验证自动生成后命中率统一提升
3. **人工辅助界面**：映射审查 + 词典编辑器 + 失败反馈回路
4. **schema linking 兜底**：运行时动态映射
5. **持续验证**：新行业加入测试矩阵
