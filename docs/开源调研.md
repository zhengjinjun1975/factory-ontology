## 落地进展

"数据→本体→Agent"最小可用路径已跑通：`data/equipment.csv` 样例 → `csv_to_owl.py` 转本体（N-Triples, 零依赖, 类型自动推断）→ `ontology_qa.py` 规则问答 + `ontology_qa_v2` LLM 语义兜底。

- 规则引擎：数量/类型/最大值/分组/状态/按编号查属性，数据准确。
- LLM 兜底：规则未命中时发本地 LLM，基于本体数据智能回答泛化问题（如"哪些设备需尽快维护"）。
- 性能：5 万条→60 万行 N-Triples 生成 1.3s；解析+问答 2.3s，大数据可用。
- 本体补全：LLM 推断设备类型→父类层级、状态→优先级。
- 泛化能力：换任何类似 CSV 数据源，无需改代码/手写词表，自动得到本体 + 中文问答。词典外置（`config/lexicon.json`）、`lexicon_agent` 自动生成、字段别名跨数据源识别。

完整流程：
```
新CSV → lexicon_agent自动词典 → csv_to_owl转本体 → query问答(指定词典)
```

边界：仍未覆盖数值范围查询、属性+属性组合、关系查询、非 CSV 数据源（DB/API）。
