# 需求：建模图件升级为力导向图（学习 sme/FDE 库）

> 用户反馈："建模图件，也应该向 sme 和 fde 那个库学习，力传导的图件，多样化链接。"
> 目标：把 model 结构图从静态 SVG 升级为 ECharts 力导向图（企业→域→实体→实例层级、多样化链接、缩放平移、分类着色），参考 sme 库 `web/instance-graph.js`。

## 参考实现
- sme 库：`E:\open-source\sme-decision-ontology\web\instance-graph.js`（先读，理解力导向图实现）
  - ECharts graph (layout 手动域列 + roam 缩放 + 标签hover防重叠 + 分类着色)
  - 层级：企业顶部 → 业务域列 → 实体类 → 实例
  - 数据：`/graph/full` 返回 {nodes:[{id,entity,domain,name}], edges:[{source,target}]}

## 现状
- `web/src/components/ModelGraph.svelte`：静态 SVG（720×360 主类+属性放射），用 `GET /api/ontology/schema`
- 后端 `ontology_schema_info.py`：返回 schema 结构（class/object_properties/type_hierarchy 等），**无实例 nodes/edges**

## 目标文件
- `E:\open-source\factory-ontology-kit\codes\ontology_schema_info.py`（后端，加 nodes/edges 输出）
- `E:\open-source\factory-ontology-kit\web\server\ontology.js` / `index.js`（若需新接口）
- `E:\open-source\factory-ontology-kit\web\src\components\ModelGraph.svelte`（前端，升级力导向图）

## 要求
### 1. 后端：提供力导向图数据
- 让 schema 接口（或新 `/api/ontology/graph`）返回 `{nodes, edges}`：
  - nodes：含企业 hub + 业务域 + 实体类 + 实例节点（带 entity/domain/name）
  - edges：实例间关系边（对象属性）+ 类→实例 + 域→实体层级边
  - 复用 ontology_schema_info 解析 .nt 的能力，扩展出实例节点和边

### 2. 前端：ModelGraph 升级为 ECharts 力导向图
- 引入 ECharts（用本地 echarts.min.js，参考 sme 的 web/lib/echarts.min.js，或 npm 安装 echarts）
- 力导向图：nodes/edges 渲染 + roam 缩放平移 + 分类着色 + 标签防重叠
- 层级布局：企业 → 域 → 实体类 → 实例（参考 sme instance-graph.js 的域列布局）
- 多样化链接：不同关系类型用不同颜色/线型（如生产/销售/质检关系不同色）
- 保留 refreshKey 触发重新加载

## 铁律
- 极简：复用 sme 的 instance-graph.js 实现思路，不改后端建模逻辑
- ECharts 用本地文件（cdn 国内可能不稳），从 sme 库复制 echarts.min.js 到 web/public/lib/
- 不破坏现有：数据建模/问答/看板
- 浅色工业风

3. 换数据重新建模后图自动刷新（refreshKey）
