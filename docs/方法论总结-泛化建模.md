# 方法论总结：本体问答泛化建模（两阶段 + 混合检索）

**核心**：让本体问答系统"换任何行业数据即用"，而非逐行业打补丁。基于 9 大行业（阀门/机械/食品/化工/地震/精加工/波纹管/环保/造船）横向验证，落地两阶段泛化建模方法论，命中率 100%。

**9 大行业泛化方案**：根源是查询映射硬编码（实体名/字段/类型），换行业即漏答。解法是"建库自动生成映射"，建模时从 suggest_schema 自动生成 `entity_cn2en`（实体计数映射，词干+中文 label 双源）+ `numeric_fields`（极值字段，data profiling 识别数值列）+ `type_cn2en`（枚举收集）+ `synonym_map`（LLM 同义词）。于是测线/炮点/项目/船/船坞等任意新行业实体自动可计数，无需改代码。

**极值解决方案**：规则引擎极值模板加通用极值词映射（`_EXTREME_WORD_FIELDS`），"最贵/最便宜"→price、"大/小"→容量/吨位、"高/低"→温度/功率，自动推断对应数值字段；叠加本地向量语义检索（nomic-embed-text + BM25 混合），语义模糊查询（"油轮有几艘"）命中。

**架构分层**：结构层（通用查询模板）与映射层（随行业自动生成）解耦，人工辅助可精细调整长尾，为未来任何行业形成可复用基础。
