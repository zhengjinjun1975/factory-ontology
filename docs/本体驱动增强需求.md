# 需求：factory-ontology 本体驱动增强（三项）

> 基于2025-2026最新技术研究（详见 knowledge/AI/articles/ 三篇研究笔记），给 factory-ontology-kit 做本体驱动增强。
> 遵循「复用优先·极简落地」方法论：优先复用 schema_ontology / 现有 graph_rag 能力，只写最少新增代码。

## 背景（技术依据，2025-2026 研究）
1. **本体引导检索路径**（OG-RAG EMNLP2025 / ORT ACL2025）：本体关系路径引导 KG 检索，显著提升多跳问答
2. **本体约束减幻觉**（clinical QA 98% vs GPT-4 37%）：本体公理约束减少 LLM 幻觉
3. **LLM 驱动本体自动构建**（LOM / schema-free）：从数据自动推断 schema，降低本体构建门槛

## 目标文件
- `E:\open-source\factory-ontology-kit\codes\graph_rag.py`（增强1）
- `E:\open-source\factory-ontology-kit\codes\logical_qa.py` 或 `ontology_qa_v3.py`（增强2）
- `E:\open-source\factory-ontology-kit\codes\schema_ontology.py`（增强3）

## 增强1：本体引导 GraphRAG 种子扩展（graph_rag.py）
- 在 `find_seeds` 后增加本体关系路径扩展：接收 schema_ontology 的关系配置（relations 的 label/id），当问题匹配关系 label 时，从已有种子沿该关系找到连接实体，补充为种子
- 极简：不引新依赖，复用现有 graph/reverse 结构
- 签名建议：`find_seeds(..., ontology=None)`，ontology 传入 schema 的关系列表
- 效果：问"车间A的设备"这类关系查询，能从"车间A"种子沿 locatedIn 关系找到设备

## 增强2：本体约束减幻觉（问答链路）
- 在 LLM 兜底（graph_rag.answer_graph / logical_qa）的 prompt 里，注入本体约束提示（"只依据提供的事实回答，不编造不在图中的关系/实体"）
- 极简：不改大结构，只在 prompt 加一句本体约束
- 可选：若 schema 有约束（unique/required），把约束注入 prompt 让 LLM 校验

## 增强3：schema 自动推断（schema_ontology.py）
- 新增 `suggest_schema(data)` 函数：从多表数据自动推断 schema（实体/关系/约束），复用 modeling 思路
- 极简：复用现有 `_infer_relations` / `_infer_prop_role`，不重复实现
- 效果：无手写 schema 时也能用 schema 驱动建模（schema-free 范式）

## 极简原则（必须遵守）
1. 标准库优先，不引新第三方依赖
2. 复用 schema_ontology / graph_rag 已有函数，不重复实现
3. 只写最少必要代码，不加抽象/框架/配置系统
4. 全程 try/except 静默容错，不抛异常中断

## 验证要求
- 增强1：问"车间A的设备"能命中设备（对比增强前）
- 增强2：prompt 含本体约束句
- 增强3：无 schema 时 suggest_schema 能推断实体/关系
- pytest 不回归（29 passed）
