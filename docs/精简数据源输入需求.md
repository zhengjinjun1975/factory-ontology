## 要求（精简为清晰的两源）
### 文件源（主要入口）
1. **移除"示例数据目录勾选"区块**（用户明确不需要）
2. 文件源 = 一个"选择文件"按钮（`<input type="file" multiple>`，浏览器多选）→ 选后显示文件列表（文件名+大小+✕移除）→ 「确认并建模」按钮 → setupOntologyMulti
3. **默认示例**：进入数据建模 tab，若未选文件，界面提示"将使用默认示例数据（data_valve 阀门数据）"，用户可直接点「用默认示例建模」或先选文件再「确认并建模」。默认示例即调 fetchExample('data_valve/valve_products.csv') 等几核心文件，或后端预置
   - 极简：提供一个「用默认示例建模」按钮，默认加载 data_valve 核心表
4. 空状态：未选文件时显示"点击选择文件，或使用默认示例"

### 数据库源（次级，折叠）
