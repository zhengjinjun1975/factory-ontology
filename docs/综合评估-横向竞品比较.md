# 综合评估：factory-ontology 横向竞品比较 + 方案最优性评估

> 目的：在完成 5 项能力改进后，横向比较竞品，综合评估当前方案在**核心加固/泛化性建模/鲁棒性问答**上是否最优，还有没有提升空间。
> 依据：《工厂本体竞品分析-2026》《工厂本体检索优化调研-2026》（Obsidian 研究笔记）+ 跨行业实测验证。

---

## 一、当前方案全景（5 项改进后）

| 能力 | 当前实现 | 依据 |
|------|---------|------|
| 词典/建模 | schema 驱动 + LLM 语义聚类合并同义词（synonym_map） | DSE-RE / AutoSchemaKG |
| 检索命中率 | 规则引擎(确定性) + GraphRAG(BFS子图+查询改写+LLM) + BM25 | CoTKR / HybGRAG |
| 兜底多样性 | 动态调温（精确查低温/开放查高温）+ schema→prompt | Selective Sampling / ShEx |
| 错误处理 | 5 族分类 + fetchRetry(429/5xx退避) + 输入guardrail | SoGuru 2025 |
| 泛化鲁棒性 | 换行业只换数据目录，suggest_schema 自动建模 | 配置化设计 |

**跨行业实测**：阀门 5/6 + 机械 6/6 + 食品 5/6 = 16/18（89%）命中率，三行业都能建个体、核心查询命中。

## 二、横向竞品比较（本体问答路线）

### 定位：factory-ontology = 面向中小工厂的"CSV→本体→问答"轻量套件

| 竞品 | 定位 | factory 相对优势 | factory 相对差距 |
|------|------|----------------|----------------|
| **Palantir AIP** | 企业级本体驱动数据智能 | 轻量、开箱即用、零治理负担 | 无动作层/权限/多源实时连接 |
| **Stardog Voicebox** | 企业 KG + LLM 问答 | 轻量、成本低 | 无 NL→图查询的确定性翻译引擎（当前靠规则模板+LLM兜底） |
| **Microsoft GraphRAG** | 文本→分层社区图谱 | 结构化数据建本体（非LLM抽图噪声） | 无非结构化文档通道 |
| **Neo4j LLM Builder** | 非结构化→KG | 本体明确可控、可解释 | 无文档建图 |
| **Chat2DB/Vanna** | Text-to-SQL | 本体约束查询空间、规避Text2SQL噪声 | 无直接落库写操作/复杂JOIN |

## 三、三方面最优性评估

### 1. 核心加固（错误处理/边界安全）— **已达工程级，接近最优**
- ✅ 5 族错误分类（基础设施/限流/语义/输入策略/未知）+ 429/5xx 退避重试 + 输入 guardrail + XSS 安全
- ✅ 对标 SoGuru 2025 生产级分类法、OpenAI guardrails
- 提升空间（低）：输出语义校验（LLM 回答幻觉检测）可加强，但成本较高、收益边际

### 2. 泛化性建模 — **已达"换数据即用"，接近最优（轻量定位下）**
- ✅ suggest_schema 自动推断 schema + LLM 语义聚类词典，换行业只换数据目录
- ✅ 跨 3 行业验证：都能建个体、核心查询命中（89%）
- 提升空间（中）：LLM 直接归纳 schema（AutoSchemaKG）替代纯规则 suggest_schema，可进一步提升 schema 语义质量；schema→prompt 已部分实现
- **诚实边界**：轻量定位决定了"够用、快、能落地"优于"W3C 完备推理"，这是刻意取舍

### 3. 鲁棒性问答 — **规则100% + 多级兜底，稳健但复杂查询有提升空间**
- ✅ 规则引擎确定性 100%（已定义场景）+ GraphRAG（查询改写+动态调温+schema→prompt）+ BM25 三级兜底
- ✅ 跨行业 89% 命中率，核心查询（设备数/极值/客户/产品信息）全部命中
- **提升空间（中-高）**：
  - 属性值类复杂查询（"不锈钢材质的阀门"/"保质期最长的产品"）仍走 LLM 兜底且可能信息不足 → 需更细的同义词/属性值覆盖
  - 可引入**重排序 rerank**（HybGRAG critic）剔除 BFS 子图噪声
  - 可升级 BYOKG-RAG 多策略 + 迭代精化（对自定义 KG 泛化更好）

---

## 四、结论

**当前方案是稳健、可落地的底座，在"轻量工厂本体问答"定位下接近最优：**
- **核心加固**：达工程级（5 族错误 + 退避重试 + guardrail），接近最优
- **泛化建模**：换数据即用（suggest_schema + 语义聚类），跨行业验证通过
- **鲁棒问答**：规则确定性 + 多级兜底，核心查询全命中

**主要提升空间（按性价比）：**
1. **属性值/材质类查询**的同义词与属性值覆盖（解决"不锈钢阀门""保质期最长"这类）
2. **检索精化**（rerank 去噪 / BYOKG-RAG 多策略）— 对复杂查询价值大
3. **LLM schema 归纳**（AutoSchemaKG）替代纯规则 — 中期

**底线判断**：5 项改进后，工具已从"能用"提升到"专业可用"，在中小工厂本体问答这一细分定位上具备竞争力；无需对标大厂重平台，坚持"本体约束 + 规则确定 + LLM 兜底 + 换数据即用"的差异化护城河。
