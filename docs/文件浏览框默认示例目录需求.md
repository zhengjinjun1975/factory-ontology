# 需求：文件浏览框默认到示例目录（学习 solo-agent-kit 的 /api/browse 方案）

> 用户反馈："浏览数据时未默认到示例数据目录。" 并指出 solo-agent-kit 套件有现成的多文件选择 + 示例目录方案。
> 学习 solo-agent-kit：`/api/browse` 后端默认根 = examples/data（示例数据直接可见）+ 目录导航 + 多文件选择。这是"默认到示例目录"的正确方案。

## 要求
### 1. 后端 /api/browse（学习 solo-agent-kit）
- 默认根 = codes/data_valve（示例数据目录，直接可见）
- `dir` 参数导航（默认 data_valve，可导航到上级/子目录/其他盘符）
