# 需求：浏览数据默认到示例数据目录（前端展示示例目录文件列表）

> 用户反馈："浏览数据的时候，依然未能默认到示例数据目录。"
> 说明：浏览器 `<input type="file">` 出于安全**无法指定默认打开路径**（这是浏览器限制）。正确解法：**前端直接展示示例数据目录的文件列表**（data_valve/data），让用户像浏览文件管理器一样看到示例文件，直接勾选/查看/建模，不依赖系统浏览框导航。

## 现状
- 后端 `GET /api/ontology/examples` 返回 22 个示例文件（分 data_valve/data 目录）：[{name, path, size}]
- 前端数据源输入区：系统文件选择（`<input type="file" multiple>`）+ "用默认示例建模"按钮
- **缺示例数据目录的文件列表展示**

## 目标文件
- `E:\open-source\factory-ontology-kit\web\src\App.svelte`（数据建模 tab 数据源输入区）

## 要求
1. **示例数据目录浏览区**：数据源输入区加"示例数据目录"区，onMount 调 fetchExamples() 加载，分目录展示（data_valve / data），每个文件显示（文件名 + 大小），**默认展开在示例目录**（用户第一眼看到示例文件，不用系统浏览框导航）
2. **点文件可操作**：
   - 点文件 → 可预览（调 fetchExample 读内容）或勾选
   - 勾选多个示例文件 → 「用所选示例建模」→ 组装 files → setupOntologyMulti
3. **保留**：系统文件选择（上传本地文件）+ "用默认示例建模"（一键 data_valve）仍可用
4. **默认即示例**：进入数据建模 tab 就看到示例目录文件列表，替代"系统浏览框"作为浏览数据的默认入口

## 约束
- Svelte 5（$state/$props，不用 export let）
- 极简：复用 fetchExamples/fetchExample/setupOntologyMulti，只加展示交互
- 浅色工业风，与现有文件列表样式一致
- 不破坏：系统文件选择/默认示例/DB接入/问答/看板
- 中文正确

## 验收
1. 数据建模 tab 默认展示示例数据目录文件列表（分 data_valve/data，文件名+大小）
2. 勾选示例文件 → 「用所选示例建模」→ 建模成功
3. 系统文件选择（本地文件）保留
4. vite build 无 error
5. pytest 29 passed
