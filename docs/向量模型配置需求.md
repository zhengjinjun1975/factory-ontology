# 需求：配置增加向量模型配置（embedding 模型纳入 model_config，默认本地）

> 用户要求：配置里增加向量模型配置，默认本地（向量检索用本地 embedding），按最终方案调整代码。

## 背景
当前 vector_retrieval.py 硬编码 embedding 模型（nomic-embed-text + 环境变量 OLLAMA_BASE），未纳入 model_config 配置体系。需把向量/embedding 模型加入配置，可配置、默认本地。

## 目标文件
- `E:\open-source\factory-ontology-kit\codes\config\model_config.json`（加 embedding 配置）
- `E:\open-source\factory-ontology-kit\codes\model_llm.py`（加 get_embedding_config）
- `E:\open-source\factory-ontology-kit\codes\vector_retrieval.py`（读配置替代硬编码）
- `E:\open-source\factory-ontology-kit\web\server\ontology.js` / `web\src\App.svelte`（前端模型配置显示向量模型，可选）

## 要求
### 1. model_config.json 加 embedding 配置（默认本地 nomic-embed-text）
```json
{
  "active": "cloud",
  "embedding": {
    "name": "本地向量模型",
    "type": "ollama",
    "base_url": "http://127.0.0.1:11434",
    "model": "nomic-embed-text",
    "api_key": ""
  },
  "models": { ... 现有 local/cloud ... }
}
```
默认本地 embedding（nomic-embed-text，Ollama）。

### 2. model_llm.py 加 get_embedding_config()
- 返回当前 embedding 模型配置（读 model_config 的 embedding 字段）
- 兜底默认 nomic-embed-text + 127.0.0.1:11434

### 3. vector_retrieval.py 读配置（替代硬编码）
- 用 get_embedding_config() 读取 embedding 模型 + base_url
- 不再硬编码 nomic-embed-text（从配置读，可改）
- 兼容：配置读取失败回落默认 nomic-embed-text（不阻塞）

### 4. 前端模型配置（可选，极简）
- 模型配置管理显示向量模型（可查看/编辑 embedding 模型），保存到 model_config

## 约束
- 极简
- 默认本地 embedding（用户要求）
- 不破坏现有功能
- 配置失败回落默认（不阻塞）
